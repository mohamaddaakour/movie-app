# TV Show Discovery and Watchlist

A TV show discovery and watchlist app being built with React, TypeScript,
Axios, React Router, TanStack Query, and Zustand.

Show data comes from the [TVmaze public API](https://www.tvmaze.com/api).
No account, API key, credentials, or environment configuration is required.
TVmaze data is licensed under [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/).

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```
